# iOS setup
Nothing to install locally. The Mac is not needed: GitHub Actions builds the app.
1. Apple Developer Program membership (done); Developer Program License Agreement accepted.
2. App ID `com.tomburkett.conversationai` registered; App Store Connect record "Conversation AI Notes".
3. GitHub secrets/variables set (see TESTFLIGHT_DEPLOYMENT.md).
4. On iPhone/iPad: install TestFlight, accept the internal-tester invite, install Ask Jeeves.
5. For summaries, flashcards and Ask: Settings > Apple Intelligence & Siri > on (iOS 26, supported device).
